# Адаптер Claude Code

Этот файл — тонкий адаптерный слой для Claude Code. Основной контракт проекта находится в `AGENTS.md` и имеет приоритет.

Дополнительные правила для Claude Code:

- Не интерпретируй этот репозиторий как обычный пользовательский проект Harness только потому, что здесь разрабатывается сам Harness.
- Не создавай встроенную в репозиторий `.harness/tools/**` как архитектуру по умолчанию: цель проекта — вынести управляющий слой Harness в устанавливаемый CLI/Core.
- Не превращай `harness` CLI в обязательную обёртку вокруг `claude` или Codex TUI.
- При проектировании интеграции с runtime сохраняй нативные разрешения Claude Code, подтверждения, вопросы пользователю и семантику интерактивной сессии.
- Транспорт и конфигурация, специфичные для Claude Code, не должны менять семантику протокола Harness Core.
- Общую логику, которая нужна также Codex, редакторским интеграциям и другим runtime-адаптерам, размещай в независимом от runtime слое Core, а не в коде, специфичном для Claude.
- Перед изменением поведения протокола сверяйся с актуальным template/reference Harness и явно отделяй устаревшую встроенную в репозиторий реализацию от целевой архитектуры CLI.
- Для проверки изменений используй штатные скрипты репозитория из `package.json`; не подменяй их незафиксированными локальными процедурами.
